# Eval 05: Implement keyboard navigation

## Task

Build a TUI with a nested menu: top-level categories, each containing items.
Navigate with arrows, enter to drill in, backspace to go up, tab to switch focus
between sidebar and main panel.

## Acceptance criteria

- Tab switches focus and focus indicator is visible
- Enter drills into category, backspace returns
- All keys documented
- No focus trap (can always quit with q/Ctrl-C)
- Works at 40x8

## Should trigger skill: yes
